# submission-v5 — Narration / Card Text

No TTS/voiceover audio was generated in this environment. Per spec, burned-in text
cards serve as the narration and timing artifact for `reference-demo-v0.mp4`. This
file records the exact wording of every card and its on-screen duration, so it can
be read as a script and/or converted to real voiceover later without re-deriving text.

All source clip segments (2b, 3, 6b, 7b, 9) are silent (no audio track in the
originals) — no narration overlays them in this reference cut; on-screen product UI
is the "narration" for those beats. Only the placeholder/annotation/explainer cards
carry text.

## If real voiceover is produced later

Card text above is written to double as a VO script — each block can be read aloud
over its beat with only light rephrasing (e.g. "CreatorPost requests Direct Post
first" reads naturally as spoken narration as-is). Reused-footage beats (2b, 3, 6b,
7b, 9) have no scripted narration here; a VO pass over those would need new lines
written against the actual on-screen actions listed in `CAPTURE-MANIFEST.md`.
