## Replacement workflow

1. Record the new segment (desktop screen capture or iPhone screen recording) at any resolution.
2. Trim/re-encode to match spec: 1920×1080, yuv420p, 30fps, h264 (`libx264 -crf 18`), no audio track — same as existing segments, so the concat step can stay a lossless stream-copy.
3. Overwrite the corresponding file under `submission-v5/segments/` (e.g. `04_stats_placeholder.mp4` → real capture, keep filename or update the list in `build-reference-cut.sh`).
4. Re-run `bash submission-v5/build-reference-cut.sh`.
